Create a Python class named Optimize_with_BO, with __init__(self, budget, dim, initial_points, random_seed) that stores the evaluation budget (60), the dimension (6), the initial DoE points (a numpy array of shape (n_init, dim) in [-5, 5]^dim) and the random seed (use it for every stochastic component, e.g. torch.manual_seed / numpy / scipy Sobol or LHS),
and a __call__(self, func) method that tries to find x in [-5, 5]^6 that minimizes func(x). func takes ONE point (1-D numpy array of length 6) and returns a float; func.bounds.lb and func.bounds.ub are the bounds.
The TOTAL number of calls to func, including the initial points, must not exceed `budget`; calls beyond the budget raise an exception. Evaluate the provided initial_points first (they count against the budget), then proceed with Bayesian optimization.
The function should return the tuple best_f, best_x (value best found and the location).
Implement an efficient and robust Bayesian Optimization algorithm for this expensive black-box task. The code you implement must
only use BoTorch and GPyTorch for the surrogate/acquisition; you may use numpy, scipy and torch for helper tasks. Do not use any other optimization libraries. You may append helper functions or classes, but the main class must be named Optimize_with_BO and must have the specified methods.
You may use BoTorch acquisition functions (qLogExpectedImprovement, qLogNoisyExpectedImprovement, qUpperConfidenceBound, ...), GPyTorch kernels (MaternKernel, ScaleKernel, ...), or design your own acquisition on top of BoTorch (e.g. SAWEI, GP-Hedge as in HEBO, trust regions, input/output warping, ensembles, restarts).
